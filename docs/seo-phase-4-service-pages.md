# SEO Phase 4 — service page coverage

This phase audits and improves public service detail coverage without replacing existing ranking URLs.

Initial findings:
- Every active catalog service is generated at `/services/{service-code}` by `app/services/[slug]/page.tsx`.
- Existing canonical India landing pages remain the primary SEO targets where already established.
- Some catalog detail pages are intentionally `noindex,follow` until they have sufficiently differentiated content.
- Phase 4 should improve service-page UX, metadata, internal links and sitemap coverage without creating duplicate competing URLs.
