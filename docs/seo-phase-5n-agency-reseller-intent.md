# Phase 5N — Agency and reseller search intent

## Search opportunity

Live India SERPs for reseller-oriented SMM queries repeatedly emphasize agency use, bulk workflows, client management, current pricing, API access and repeat operations. SocialRUSH already has real agency infrastructure, so a new thin reseller doorway page would split authority unnecessarily.

## Canonical decision

- `/for-agencies` is the single canonical owner for:
  - SMM reseller panel India
  - SMM panel for agencies India
  - social media reseller panel India
- `/smm-reseller-panel-india` redirects to `/for-agencies`.
- `/smm-panel-for-agencies-india` redirects to `/for-agencies`.
- No separate indexable reseller doorway page is created.

## Visible authority upgrade

The agency page now explains the actual SocialRUSH workflow:
- client and campaign organization;
- bulk job planning;
- saved monthly plans and renewal review;
- campaign stacks;
- signed-in API documentation;
- verified per-order checkout and tracking.

## Commercial integrity

The page explicitly does not promise:
- a white-label child panel;
- automatic wholesale discounts;
- guaranteed delivery outcomes;
- guaranteed reseller profit;
- automatic recurring charges.

Current service availability, limits, delivery/refill conditions and payable totals remain authoritative in the live service/order flow.

## Search release controls

- query ownership registry covers both reseller aliases;
- production SEO health monitoring verifies redirects and the canonical page;
- `/for-agencies` is included in the Phase 5 IndexNow release list;
- the sitemap receives a truthful significant-update date of 2026-09-28 for `/for-agencies` without changing earlier Phase 5 dates.
