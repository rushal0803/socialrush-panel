# Repeat Revenue + Retention upgrade

This batch makes completed campaigns easier to repeat from order history on desktop and mobile.

- Adds a prominent repeat-last-order CTA when a completed service can be mapped to the live catalog.
- Keeps the existing service, quantity and profile-link prefill flow.
- Adds `repeat_order_click` analytics with source context.
- Clearly states that current live pricing applies before checkout.
- Keeps payment, wallet, supplier routing, verification and order-creation semantics unchanged.
