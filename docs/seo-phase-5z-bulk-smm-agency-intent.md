# Phase 5Z — Bulk SMM / agency fulfillment intent

## Goal

Capture high-intent India searches around bulk SMM orders, bulk social-media services and multi-client agency fulfillment without creating a duplicate commercial landing page.

## Canonical ownership

- Canonical page: `/for-agencies`
- Redirect-only aliases:
  - `/bulk-smm-orders-india`
  - `/bulk-smm-services-india`
  - `/bulk-social-media-services-india`
  - `/agency-social-media-fulfillment-india`

These aliases belong to the existing agency/reseller query owner so there is one canonical target.

## Product truth

SocialRUSH currently supports agency/client workspaces, campaign attribution, bulk planning, monthly plan workflows, tracked order history and available API documentation.

This phase does **not** claim:
- a white-label child panel,
- automatic wholesale pricing,
- automatic bulk discounts,
- automatic orders or charges,
- guaranteed delivery outcomes.

## On-page additions

The agency page gains a dedicated Bulk SMM Orders India authority section that explains:
- client/destination separation,
- current-price review,
- service-by-service delivery/refill review,
- human review before payment,
- multi-platform planning,
- repeat-agency workflows.

FAQ schema is extended with bulk-order questions that match visible copy.

## Search-data limitation

Fresh Google Search Console data was unavailable because the GSC Wizard subscription is inactive. Semrush API units were also unavailable. Phase 5Z therefore uses live SERP review plus existing product/catalog architecture and keeps all claims constrained to confirmed SocialRUSH functionality.
